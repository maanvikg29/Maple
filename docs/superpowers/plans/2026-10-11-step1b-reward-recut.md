# Step 1B: the focus reward table — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** replace the 19-category sleep-first reward table with the focus spec's 7 categories (155 leaves = 114 hours saved + 40 secondary + 1 first leaf). Alongside the table:
- put the most threatened maples on the top rungs, with a sourced line in leaf detail;
- make Home's next leaf the next hours-saved rung;
- remove the bedtime-run streak and the categories that no longer exist.

**Architecture:** the reward table is data in `MapleCore/Resources/rewards.json`. It is generated by a committed, deterministic script, `Scripts/generate-rewards.py`, from:
- `species.json`, which gains IUCN `conservation` data;
- the archived 2026-10-10 table, used only for the species' journey order.

Code keys everything on `RewardCategoryID` and `RewardCategoryInfo`. The migration runs in a fixed order:
1. add the new categories next to the old ones;
2. switch the table and the two live data paths (the first leaf, and Apple Health's on-time nights → `rested_nights`);
3. change the behaviour the spec asks for (the next leaf, the streak, Profile);
4. delete the old categories once nothing uses them.

Every task ends with a green build and test run.

**Tech stack:** Swift 6.4 (language mode 6), SwiftUI, iOS 27 SDK, Swift Testing, Python 3 (the generator only, run with `python3 -I`).

**Spec:** `docs/superpowers/specs/2026-10-11-focus-hours-saved-design.md`, chiefly §4 (reward table), §4.5 (next leaf), §6 (Home) and §12 (documents). Plan 1A (`docs/superpowers/plans/2026-10-11-step1a-merge-m1-branches.md`) must be finished first. This plan continues on the same branch, `maanvik/focus-step1`.

## Global constraints
- iPhone only, iOS 27 minimum, Swift 6 strict concurrency, zero warnings in Debug and Release.
- Swift Testing. Tests come before the change they check.
- DEBUG-only demo code.
- `MapleCore` stays pure Foundation, `Sendable` and nonisolated.
- **The table (spec §4.1):**

  | Category | Rungs |
  |---|---|
  | `first_leaf` | 1 |
  | `hours_saved` | 114, from 1 to 2,000 (the §4.2 list) |
  | `sessions_finished` | 1, 10, 25, 50, 100, 250, 500, 1000 |

  | `bedtime_kept` | 1, 7, 25, 50, 100, 200, 365 |
  | `rested_nights` | 3, 14, 30, 60, 100, 175, 250, 365 |

  Every species is used exactly once, and no two leaves share a rung.
- **Placement (§4.3):**
  - famous garden species go on early and landmark rungs;
  - the top 10 hours rungs and the top rung of each secondary ladder go to the most threatened maples (CR, then EN, then VU);
  - u-confidence species stay on late rungs (D3);
  - evergreens go on the consistency ladders (streak, mornings, bedtime).

  - `hours_saved`, `sessions_finished` and `focus_streak` ship with F1;
  - `phone_free_mornings` and `bedtime_kept` ship with F2.
- Sleep leaves come only from Apple Health (D9).

/// IUCN Red List categories Maple shows.
public enum RedListCategory: String, Codable, Sendable, CaseIterable {
    case cr = "CR", en = "EN", vu = "VU", nt = "NT", lc = "LC", dd = "DD"

    public var displayName: String {
        switch self {
        case .cr: "Critically endangered"
        case .en: "Endangered"
        case .vu: "Vulnerable"
        case .nt: "Near threatened"
        case .lc: "Least concern"
        case .dd: "Data deficient"
        }
    }

    /// Critically endangered, Endangered or Vulnerable.
    public var isThreatened: Bool { self == .cr || self == .en || self == .vu }
}
```

    /// "Endangered · IUCN Red List, 2020", plus the sourced note when there is one; nil unless the species is
    /// threatened (Critically endangered, Endangered or Vulnerable). Focus spec §4.3.
    public static func conservationLine(_ status: LeafSpecies.Conservation?) -> String? {
        guard let status, status.category.isThreatened else { return nil }
        var parts = [status.category.displayName, "IUCN Red List, \(status.year)"]
        if let note = status.note, !note.isEmpty { parts.append(note) }
        return parts.joined(separator: " · ")
    }
```

def days(category, threshold):
    """Days to the rung for a committed member at the category's design pace."""
    return 0 if category == "first_leaf" else threshold / PACE[category]


def tier(category, threshold):
    """Journey tier from the design days (rewards.md): up to 8, 45, 180, more; the top of a ladder over a year."""
    if category == "first_leaf":
        return "first-steps"
    d = days(category, threshold)
    if threshold == LADDER[category][-1] and d > 365:
        return "legendary"
    if d <= 8:
        return "first-steps"
    if d <= 45:
        return "common"
    if d <= 180:
        return "uncommon"
    return "rare"


def unlock_text(category, n):
    if category == "first_leaf":
        return "Plant your maple"
    if category == "hours_saved":
        text = "Save 1 hour" if n == 1 else f"Save {n:,} hours"
        return f"{text} · {LANDMARKS[n]}" if n in LANDMARKS else text
    if category == "sessions_finished":
        return "Finish your first session" if n == 1 else f"Finish {n:,} sessions"
    if category == "focus_streak":
        return f"A {n}-day focus streak"
    if category == "phone_free_mornings":
        return "Your first phone-free morning" if n == 1 else f"{n} phone-free mornings"
    if category == "bedtime_kept":
        return "Keep your first bedtime" if n == 1 else f"Keep {n} bedtimes"
    if category == "rested_nights":
        return f"{n} rested nights"
    raise ValueError(category)


def first_sentence(text):
    head = text.split(". ")[0].rstrip(".")
    return head + "."


def main():
    species = json.loads(SPECIES.read_text())
    by_id = {s["id"]: s for s in species}
    old = json.loads(OLD.read_text())["assignments"]
    rank = {a["species_id"]: (OLD_TIERS.index(a["tier"]), a["threshold"] / OLD_PACE[a["category_id"]], a["species_id"])
            for a in old}
    about = {a["species_id"]: first_sentence(a["rationale"]) for a in old}
    rungs = [(c[0], t) for c in CATEGORIES for t in c[6]]
    assert len(rungs) == len(species) == len(set(rungs)) == 155, (len(rungs), len(species))
    assert set(rank) == set(by_id), set(rank) ^ set(by_id)

    placed = {}
    used = set()

    def place(rung, species_id, reason):
        assert rung not in placed and species_id not in used, (rung, species_id)
        placed[rung] = (species_id, reason)
        used.add(species_id)

    for rung, species_id in PINS.items():
        assert species_id in by_id, species_id
        place(rung, species_id, "a well-known garden maple on an early or landmark rung")

    top = [("hours_saved", t) for t in HOURS[-10:]] + [(c, LADDER[c][-1]) for c in SECONDARY]
    top.sort(key=lambda r: (-days(*r), ORDER[r[0]]))
    threatened = sorted(
        (s for s in species if (s.get("conservation") or {}).get("category") in SEVERITY and s["id"] not in used),
        key=lambda s: (SEVERITY[s["conservation"]["category"]], tuple(-x if isinstance(x, (int, float)) else x
                                                                       for x in rank[s["id"]][:2]), s["id"]),
    )
    for rung, s in zip(top, threatened):
        status = s["conservation"]
        place(rung, s["id"], f"IUCN {status['category']} ({status['year']}) on one of the hardest rungs")
    unfilled = top[len(threatened):]

    consistency = sorted((r for r in rungs if r[0] in CONSISTENCY and r not in placed and r[1] != LADDER[r[0]][-1]),
                         key=lambda r: (days(*r), ORDER[r[0]]))
    # u-confidence evergreens stay out: they belong on late rungs (D3).
    evergreens = sorted((s for s in species if s["evergreen"] and s["confidence"] != "u" and s["id"] not in used),
                        key=lambda s: rank[s["id"]])
    for rung, s in zip(consistency, evergreens):
        place(rung, s["id"], "an evergreen on a consistency ladder: it stays green, like the habit")

    rest_rungs = sorted((r for r in rungs if r not in placed), key=lambda r: (days(*r), ORDER[r[0]], r[1]))
    rest_species = sorted((s for s in species if s["id"] not in used),
                          key=lambda s: (s["confidence"] == "u", rank[s["id"]]))
    assert len(rest_rungs) == len(rest_species)
    for rung, s in zip(rest_rungs, rest_species):
        reason = "u-confidence, kept on a late rung (D3)" if s["confidence"] == "u" else "in journey order"
        place(rung, s["id"], reason)

    assignments = []
    for (category, threshold) in sorted(placed, key=lambda r: (ORDER[r[0]], r[1])):
        species_id, reason = placed[(category, threshold)]
        assignments.append({
            "species_id": species_id,
            "category_id": category,
            "threshold": threshold,
            "unlock_text": unlock_text(category, threshold),
            "tier": tier(category, threshold),
            "rationale": f"{about[species_id]} Re-cut 2026-10-11: {reason}.",
        })
    categories = [{"id": c[0], "name": c[1], "metric": c[2], "unit": c[3], "data_source": c[4],
                   "available_from": c[5], "ladder": c[6]} for c in CATEGORIES]
    OUT.write_text(json.dumps({"categories": categories, "assignments": assignments}, indent=2, ensure_ascii=False) + "\n")

    tiers = {}
    for a in assignments:
        tiers[a["tier"]] = tiers.get(a["tier"], 0) + 1
    print(f"{len(assignments)} leaves; tiers {dict(sorted(tiers.items()))}")
    print(f"{len(threatened[:len(top)])} of {len(top)} top rungs hold threatened species")
    if unfilled:
        print(f"note: {len(unfilled)} top rungs had no threatened species left and took the general order: {unfilled}")


if __name__ == "__main__":
    main()

    /// left out (focus spec §4.1, §4.5: sleep is never Home's automatic next leaf in a focus build).
    public var homeCandidates: [LeafProgress] {
        let focusShipped = progress.contains { $0.category != .restedNights && $0.category != .firstLeaf && $0.availability != .dormant }
        return focusShipped ? candidates.filter { $0.category != .restedNights } : candidates
    }

    /// Home's next leaf (focus spec §4.5): a pinned leaf while it is locked and available; otherwise the lowest
    /// hours-saved rung; otherwise the closest of Home's candidates.
    public func next(pinned: String?) -> LeafProgress? {
        if let pinned, let leaf = progress.first(where: { $0.speciesID == pinned }), leaf.state == .locked, leaf.availability == .available {
            return leaf
        }
        if let hours = homeCandidates.first(where: { $0.category == .hoursSaved }) { return hours }
        return Self.sorted(homeCandidates).first
    }

    /// The tree's buds: the 3 closest candidates, always including Home's next leaf, which comes first.
    public func buds(pinned: String?) -> [LeafProgress] {
        let closest = Array(Self.sorted(candidates).prefix(Self.budCount))
        guard let next = next(pinned: pinned) else { return closest }
        let others = closest.filter { $0.speciesID != next.speciesID }
        return [next] + others.prefix(Self.budCount - 1)
    }
